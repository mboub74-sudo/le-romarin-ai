# Le Romarin AI

AI-assisted French learning web app for primary pupils (1AP–6AP), designed for French-first tutoring with Arabic/Darija support, exercise help, voice-oriented learning and progress tracking.

## Development

```bash
npm install
npm run dev
```

V1 UI scaffold built with Next.js and TypeScript. AI, camera/OCR, authentication, database and speech services are intentionally not wired yet.
